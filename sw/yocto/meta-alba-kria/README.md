# meta-alba-kria

ALBA's Yocto layer for boards built on the AMD Kria K26 SOM, on top of the
AMD Embedded Development Framework (EDF).

- `conf/templates/default/`: the build configuration. `make setup` creates
  `build/yocto/conf` from it (TEMPLATECONF); edit the templates here, not
  the generated copies.
- `recipes-bsp/bootbin/`: BOOT.BIN without a bitstream (PS-only designs).
- `recipes-core/images/`: disk image as `.wic.gz`; login user `alba`
  (password `alba`, sudo) instead of EDF's `amd-edf`. Root stays locked.
- `recipes-core/systemd/`: kernel command line of the systemd-boot entry
  (serial and DisplayPort consoles, `clk_ignore_unused`, `cma=900M`), and an
  optional static address for `end0` (GEM0) instead of DHCP.

Each setting is an `ALBA_*` variable; override it in `build/yocto/conf/local.conf`
(examples at the end of the `local.conf.sample` template).

Machines are named `<som>-<carrier>-sdt` (`k26-fim2-sdt`, `k26-kr260-sdt`)
and generated by `make CARRIER=<carrier> machine` from that carrier's system
device tree; they are not part of this layer yet.

Depends on: openembedded-core, meta-xilinx-core (via EDF, scarthgap).
